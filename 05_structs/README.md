# 05 — Structs

Your first custom data type. Goal: group related fields into one type
and access them with the dot operator — the conceptual bridge from
loose variables to classes.

## Files (in learning order)

| # | File | What it teaches |
|---|------|-----------------|
| 01 | `01_struct_basics.cpp` | Declaring a `struct` (name, GPA, enrollment), creating instances, field access via `.` |

## Prerequisites

Complete [`01_basics`](../01_basics). Structs are the stepping stone to
[`06_oop_fundamentals`](../06_oop_fundamentals).
