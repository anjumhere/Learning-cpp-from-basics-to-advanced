# C++ Practice Repository

A collection of C++ practice programs, scripts, and foundational exercises built while learning C++ fundamentals (control flow, loops, functions, and standard library components).

## Repository Structure

- **`basics.cpp`**: General introductory syntax and basic language experiments.
- **`first.cpp`**: Initial introductory program scripts.
- **`triangle.cpp`**: Right-triangle hypotenuse calculator using user input and mathematical functions.

## Getting Started

To compile and run any of the files locally using a modern C++ compiler (like `g++`), run:

```bash
g++ -std=c++17 filename.cpp -o output
./output
```
