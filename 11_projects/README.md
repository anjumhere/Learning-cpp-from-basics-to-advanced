# 10 — Projects

Applied mini-projects that combine everything from folders 01–09.
Goal: read complete programs as designs, then extend them yourself via
the CHALLENGE blocks inside each file.

These are full working programs — run them first, then work through
the commented challenges (uncomment, modify, recompile).

## Files (in learning order)

| # | File | What it teaches |
|---|------|-----------------|
| 01 | `01_rock_paper_scissors.cpp` | Functions with prototypes, game loop to 5 points, `switch` rules, seeded RNG, input validation |
| 02 | `02_number_guessing_game.cpp` | `do-while` feedback loop, `rand()` ranges, attempt counting |
| 03 | `03_quiz_game.cpp` | Parallel data arrays (`std::array`, 2D options), `toupper()` answer checking, score accumulation |
| 04 | `04_banking_system.cpp` | Menu-driven design: `do-while` + `switch`, helper functions per operation, overdraft guards |
| 05 | `05_credit_card_validator.cpp` | The Luhn algorithm end-to-end: positional digit math and checksum validation |
| 06 | `06_debugging_spot_the_bug.cpp` | Deliberately broken Luhn draft — find all the bugs using the progressive hints |
| 07 | `07_ration_distributor.cpp` | Finite-stock simulation: state updates in a while-until-empty loop, over-allocation guards |

## Prerequisites

All of folders 01–09. Project 06 additionally requires having studied
project 05 (it is the broken version of the same algorithm).
